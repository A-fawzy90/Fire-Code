# مساعد الكود المصري لحريق والاشتراطات الهندسية
### Egyptian Fire Code & Life Safety Assistant (Code 305 & Decree 255/2026)

منصة وتطبيق ويب متكامل لمطابقة ومراجعة اشتراطات الكود المصري لحماية المنشآت من أخطار الحريق (كود رقم 305) والقرار الوزاري رقم 255 لسنة 2026، مع قارئ كود حر ومحلل مخططات هندسية ومستشار ذكاء اصطناعي متخصص.

---

## 🌟 الميزات الرئيسية (Key Features)

### 1. تقييم ومطابقة المشاريع الهندسية (Compliance Assessment)
- تصنيف الإشغال ومستوى الخطورة بدقة استناداً إلى جدول 2-1 والقرار الوزاري 255 لسنة 2026.
- حساب ارتفاع المبنى وفق الضوابط الدقيقة للكود المصري (حتى منسوب أرضية أعلى طابق صالح للإشغال).
- التحقق التلقائي من متطلبات الحماية الإلزامية:
  - **الأعمال المعمارية ومسالك الهروب**: مسافات الارتحال، عرض الأبواب وسلالم الهروب المحمية، مقاومات الحريق للجدران، رامبات البدروم، ومخارج الطوارئ.
  - **الأعمال الميكانيكية**: شبكات الرشاشات التلقائية (Sprinkler Systems)، صناديق الحريق الرطبة والجافة (Fire Hose Cabinets)، طلمبات الحريق، وأنظمة سحب الدخان وتهوية الجراجات.
  - **الأعمال الكهربائية والإنذار**: أنظمة الإنذار المعنونة والعادية، إضاءة الطوارئ واللوحات الإرشادية المضيئة، والمولدات الاحتياطية.

### 2. متصفح الكود الكامل (Full Code Free Reader)
- تصفح كامل وشامل لجميع أجزاء الكود المصري:
  - **الجزء الأول (305/1)**: مسالك الهروب والاشتراطات المعمارية.
  - **الجزء الثاني (305/2)**: أنظمة الإطفاء والمكافحة التلقائية واليدوية.
  - **الجزء الثالث (305/3)**: أنظمة الإنذار والكشف والتهوية والتحكم في الدخان.
  - **القرار الوزاري رقم 255 لسنة 2026** ومحددات المنشآت القائمة والجديدة.
  - **جدول 2-1 الاسترشادي الكامل** لتصنيف كافة الإشغالات ومستويات الخطورة.
- فهرس شجري جانبي سريع، بحث ذكي فوري، تكبير وتصغير مقاس الخط، وإمكانية سؤال المستشار الذكي عن أي بند بنقرة زر.

### 3. محلل مخططات الأوتوكاد (CAD / DXF Viewer & Parser)
- إمكانية رفع وقراءة ملفات الـ DXF والمخططات ثنائية الأبعاد مباشرة في المتصفح.
- استعراض الطبقات (Layers) والكتل (Blocks) ومطابقة مخارج الطوارئ ومسافات الهروب على المخطط الفعلي.

### 4. المستشار الذكي للكود المصري (AI Fire Code Consultant)
- مستشار هندسي خبير يستند حصرياً إلى نصوص الكود المصري والقرارات الرسمية المعتمدة.
- إجابات موثقة بأرقام البنود والجداول الرسمية مع شرح الخطوات التصميمية والحسابات الهيدروليكية والمعمارية.

### 5. إدارة متقدمة للمشاريع والتقارير
- إنشاء وإدارة المشاريع الهندسية، مع إمكانية حذف المشاريع أو استعادة المشاريع النموذجية.
- توليد تقارير الامتثال الرسمية بنقرة زر واحدة وتصديرها بصيغة تقارير فنية قابلة للطباعة والاعتماد.

## 🚀 البدء والتشغيل (Getting Started)

### متطلبات التشغيل:
- Node.js (الإصدار 18 فما فوق)
- npm أو yarn

### خطوات التثبيت:
```bash
# استنساخ المستودع
git clone https://github.com/A-fawzy90/Fire-Code.git
cd Fire-Code

# تثبيت الحزم والمكتبات
npm install

# تشغيل خادم التطوير المحلي
npm run dev
```

التطبيق سيعمل مباشرة على:
`http://localhost:5173/`

### بناء النسخة الإنتاجية (Production Build):
```bash
npm run build
```
